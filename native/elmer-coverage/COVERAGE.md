# Quick-suite coverage of the Rust-native Elmer

Generated by `elmer-coverage run` from `main` at `9736077` on 2026-10-29. Do not edit by hand; `results.tsv` beside this file has one row per test.

Every ctest `quick` test of the pristine build tree (`ctest -N -L quick`) is staged in a scratch directory, its mesh is generated with the pristine `ElmerGrid` exactly as its `runtest.cmake` does, and its `.sif` is run through `elmer-run`'s `NativeEngine` (the engine behind `elmer-cli`) with `elmer-sif` as parser. The oracle is the case's own `Reference Norm` and `Reference Norm Tolerance` (default 1e-5), applied by `CompareToReferenceSolution`; a test matches when `TEST.PASSED` is `1`. A test with more than one process runs under `mpirun -np N elmer-mpi-run` once the static screen passes, and matches when `TEST.PASSED_N` is `1`; without an `elmer-mpi-run` binary next to the harness it is refused as `mpi: np=N`.
